# **App Name**: VedaHire

## Core Features:

- ATS Resume Analysis: Analyze uploaded (pdf,docx) and parse the  resumes against job descriptions to provide an ATS score and identify areas for improvement.
- Resume Content Scoring: LLM tool assesses resume sections based on job requirements and provides a match score for each, focusing on skills, experience, and keywords.
- Resume Optimization Suggestions: AI-driven suggestions for optimizing the resume based on job description, highlighting missing keywords and skill gaps.
- Resume Generation: Generate a new resume based on the user's profile and selected job role.
- Cover Letter Generation: Generate a cover letter tailored to the resume and job description.
- Download/Export Options: Offer users the option to download and export their analyzed/generated resumes and cover letters in various formats (PDF, DOCX).
- User Input Forms: Enable users to upload resumes (PDF or DOCX), paste job descriptions, and select a job role.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) for a professional and trustworthy feel.
- Background color: Light gray (#F0F0F0) to provide a clean and modern backdrop.
- Accent color: Vivid orange (#FF9800) to highlight actionable items and important feedback.
- Headline font: 'Poppins' (sans-serif) for a clean and modern heading style.
- Body font: 'PT Sans' (sans-serif) for readable and accessible body text.
- Use professional and clear icons to represent different features and feedback elements.
- Maintain a clean and structured layout to present the analysis and suggestions in an organized manner.
- Implement subtle animations during the analysis and suggestion loading process to enhance user experience.
